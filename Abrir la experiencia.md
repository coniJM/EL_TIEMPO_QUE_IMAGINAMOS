# El tiempo que imaginamos

## Abrir la experiencia

En VS Code, abre Terminal → Nueva terminal y ejecuta:

~~~sh
node js/servidor.js
~~~

Deja la terminal abierta. En el Mac, abre http://localhost:8787 para la experiencia y http://localhost:8787/visualizacion.html para la flor colectiva.

Para verla desde otro dispositivo, conecta ambos a la misma red Wi-Fi y reemplaza localhost por la IP local del Mac.

Las respuestas se guardan en data/respuestas.json. Ese archivo está excluido de Git para no publicar reflexiones de participantes.
